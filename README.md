# BubbleRover

Website and brand files for BubbleRover, Logan's mobile car detailing and trash can cleaning business.

- **Car detail:** $50 per car
- **Trash can cleaning:** $15 per can
- **Book:** text or call (475) 318-2616
- **Site:** https://bubblerover.com

## What's here

| Folder | Contents |
| --- | --- |
| `public/` | The website. Vercel serves this folder as-is (no build step). |
| `brand/` | Logo files: full logo, white version for dark backgrounds, round badge. |
| `print/` | QR code (links to bubblerover.com) and the "Scan to book" flyer card. |

## Booking calendar

`public/index.html` has a `BOOKING_URL` constant near the bottom. Paste a Calendly, Google Calendar appointment, or Cal.com booking link there and the page shows the calendar. Logan sets his open hours in that app.
